JA_SELLZ PRODUCT + INVENTORY GUIDE

The storefront now has product detail pages, multiple photos, size selection, stock tracking, and a protected admin page.

ADMIN
1. In Render Environment Variables, add ADMIN_PASSWORD with a strong password.
2. Open https://YOUR-STORE.onrender.com/admin.html
3. Log in with that password.
4. Change price, total stock, size stock, and upload additional photos.
5. Click Save changes.

PRODUCT DATA
Each product in products.json supports:
- name
- category
- price
- stock
- sizes (for example S/M/L/XL)
- image (main image)
- images (gallery images)

All current stock quantities and size quantities are intentionally 0.

IMPORTANT STORAGE NOTE
The admin page writes inventory to products.json on the server. Render's normal filesystem can be reset when a service is rebuilt/redeployed. For permanent inventory management, use a persistent disk or database. Do not rely on the admin page as permanent storage until that is configured.
